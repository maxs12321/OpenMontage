# Жирафик Трафик — бренд для монтажа

Бренд блога Ильи Даниленко про РКО, регистрацию ИП и арбитраж трафика на
банковские продукты. **Это стиль по умолчанию для всех роликов в этом репозитории.**

- Плейбук стиля: [`styles/jirafik-trafik.yaml`](../../styles/jirafik-trafik.yaml) (`load_playbook("jirafik-trafik")`)
- Аватар/логотип: [`avatar.png`](avatar.png) — жираф в синем костюме с цепью RKO, круг 900×900, прозрачный фон
- Фишка блога: [`tea-ceremony.jpg`](tea-ceremony.jpg) — китайская чайная церемония («понедельник, 14:00, и ты сам решаешь»)
- Шрифты: [`fonts/`](fonts) — Lora (заголовки) и Inter (всё остальное), variable TTF с кириллицей, SIL OFL

## Основной формат

Илья снимает себя на камеру и рассказывает про нишу → пайплайн `talking-head`.
Платные ключи не используются: распознавание речи — локальный `faster-whisper`
(`transcriber`), без генерации картинок/видео/озвучки.

Типовая сборка: вырезать паузы и оговорки (`silence_cutter`) → 9:16 (`auto_reframe`)
→ лёгкая цветокоррекция (`color_grade`) → субтитры по словам (`remotion_caption_burn`)
→ тихая музыка (`pixabay_music`, громкость 0.08, ducking под голос).

## Субтитры (`remotion_caption_burn`, простой режим)

Проверено рендером 2026-10-14: кириллица в Inter, плашка и подсветка корректны.

```json
{
  "words_per_page": 3,
  "font_size": 64,
  "highlight_color": "#F28A2E",
  "caption_color": "#FFFFFF",
  "caption_background_color": "rgba(20, 24, 58, 0.80)",
  "caption_font_family": "Inter, sans-serif"
}
```

Передавай `corrections` для терминов, которые whisper путает: `{"рко": "РКО", "ип": "ИП", "т-банк": "Т-Банк", "псб": "ПСБ", "втб": "ВТБ", "аусн": "АУСН", "нпд": "НПД"}`.

Шрифты должны быть видны Chromium: перед рендером
`mkdir -p ~/.fonts && cp brand/jirafik-trafik/fonts/*.ttf ~/.fonts/ && fc-cache -f`.

**Облачная сессия Claude Code:** Remotion не может скачать свой браузер
(`ENOTFOUND remotion.media`). Рендерь с
`--browser-executable=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`
(команду `npx remotion render TalkingHead --props=...` можно запустить вручную из
`remotion-composer/` с тем же props-файлом, который пишет инструмент).

## Голос бренда (для заголовков, текста на экране, описаний)

- На «ты», как старший друг, который прошёл этот путь. Со взрослыми клиентами на регистрации — на «вы».
- Живо, с кусочками жизни, честно про подвохи. Сложное — через простую логику. В конце — вопрос к аудитории.
- Так звучим: «Не „кнопку бабло“ и не 40 уроков воды за 50к. Только то, чем пользуемся сами». «Вопрос не „заплатит или кинет“. Вопрос — выполнил ты условие или нет».
- Так не звучим: канцелярит, обещания лёгких миллионов, давление («осталось 2 места»), мат, высокомерие к новичкам, сухая заумь.
- Эмодзи — 1–3 на пост, как акцент.

(TikTok/YouTube/Instagram), начинающие ИП и самозанятые, люди в поиске подработки (Авито).

## Монтажные приёмы (из референсов и обучения Ильи)

Это набор инструментов, а не чек-лист: в ролик берём только то, что усиливает
конкретный момент. Неиспользованное — для следующих роликов.

- **Хук** (`hookStyle: "lower"`): 2 коротких слова крупным узким Oswald 700 ЗАГЛАВНЫМИ
  в два цвета (оранжевый / белый), над ними мелкая подпись курсивом Inter.
  Держится ~2.5 с, пока это звучит, — чтобы успели прочитать. Без вспышек и
  нагромождения текста. Подпись может держать открытую петлю («в конце — скрин
  выплаты»), только если в конце это правда есть.
- **Субтитры — стандарт** (`captionStyle: "word"`): одно слово за раз, белый Inter
  800 курсивом, строчными как сказано, по центру кадра (~62 % высоты), без обводки,
  мягкая тень, лёгкий «отскок» при появлении. Ключевые слова (`key: true`) — на
  оранжевой плашке `#F28A2E` с тёмно-синим текстом (не курсив). Выделять 5–10 %
  слов — те, на которые падает смысл/ударение.
- **Звуки = анимация текста** (принцип из обучения): появление заголовка → «appear»,
  плашка ключевого слова → клик мыши, фото выезжает → короткий вжух, стикер сбоку →
  свайп, текст печатается → печать Mac, счётчик растёт → «gauge», итог → «ding».
  Без синтезированных звуков. Громкость 0.3–0.5, не накладывать два звука ближе 0.3 с.
  Сэмплы лежат в `remotion-composer/public/jirafik/sfx2-*`, `sfx3-*` (локально, не в git).
- **Плавность**: без рывков и размытия на склейках, только мягкий наезд.
- **В запасе**: огромный текст по слогам за спиной («НИ / КО / ГДА») для одного
  сильного акцента; «ТЫК»/указатель/кружок на интерфейсе; метки «ПРАВИЛО #1»;
  мокап телефона; счётчик-проценты.
- **Правда прежде всего**: суммы/выплаты/результаты показываем только там, где Илья подтвердил, что это правда и к месту. Доход по арбитражу считается в конце месяца — «итог дня» деньгами не показываем.
- **Финал-награда**: один скрин результата с растущим счётчиком; подпись точно
  говорит, что это (например «личный кабинет Ozon Банка»), не «итог недели».
- **Без концовки с жирафом**, если Илья не попросит.

## Стандарт качества (с 16.10, по фидбеку Ильи)

- **Цвет**: никаких «фильтров» и виньетки. iPhone HDR (HLG) → SDR через `tonemap=hable` (npl=100)
  + `curves=all='0/0 0.5/0.56 1/1'` + убрать тёплый сдвиг `colorchannelmixer=rr=0.98:gg=0.99:bb=1.09,eq=saturation=0.95`.
  Белое должно быть белым, без оранжевого оттенка.
- **Плашки на светлом видео — светлые** (`plateTheme: "light"`): белая карточка, тёмно-синий текст,
  оранжевый акцент. Тёмно-синие плашки — только на тёмных кадрах.
- **Крупный текст за спиной** (`bigWords` + `personSrc`): 3–5 самых сильных слов ролика огромным
  Oswald оранжевым ЗА человеком. Вырезка человека — Robust Video Matting (`/home/user/models/rvm`,
  скрипт matte.py → прозрачный webm). Обычные субтитры по слову остаются спереди.
  Текст по слогам столбиком («АЛЬ/ФА»), слева, позиция по голове (headpos.py): низ текста ≈ макушка + 170px,
  чтобы голова всегда перекрывала буквы. Ставить в сильные моменты, когда это уместно.
- **Звуки — разные, по смыслу** (не один клик на всё): заголовок/плашка появилась → appear;
  плашка «№» выезжает → swipe / whoosh по очереди; крупное слово за спиной → zoom (Fuwa);
  суммы → gauge; «платный/тариф» → charge; термин → camera-click; расчёт печатается → mac-typing, итог → ding;
  призыв в конце → paper-turn. Обычные ключевые слова → mouse-click, но не подряд.
- **Сколько звуков — столько появлений**: каждый звук совпадает с отдельным появлением на экране.
  Диапазон «от 10 до 20» — два появления («от 10», потом «до 20 тысяч ₽»), два клика.
- **Без полоски прогресса сверху** (`showProgress: false`).
- **Крупный текст за спиной — только названия/главные сущности** (банки и т.п.), не эмоциональные слова вроде «соврал», «бесплатно».
- **Смена крупности** (`jumpZoom: 0.12` + `jumpRanges`): только 3–4 раза за ролик, на планах с ключевым моментом
  (новый пункт списка, расчёт, призыв). Не на каждой склейке — иначе дёргано.
- **Шрифт крупного текста за спиной меняется по смыслу**: Альфа — Unbounded Black, ПСБ — Russo One,
  Т-Банк — Lora Bold Italic (шрифты в `brand/jirafik-trafik/fonts`, ставить в ~/.fonts перед рендером).
