# Жирафик Трафик — бренд для монтажа

Бренд блога Ильи Даниленко про РКО, регистрацию ИП и арбитраж трафика на
банковские продукты. **Это стиль по умолчанию для всех роликов в этом репозитории.**

- Плейбук стиля: [`styles/jirafik-trafik.yaml`](../../styles/jirafik-trafik.yaml) (`load_playbook("jirafik-trafik")`)
- Аватар/логотип: [`avatar.png`](avatar.png) — жираф в синем костюме с цепью RKO, круг 900×900, прозрачный фон
- Фишка блога: [`tea-ceremony.jpg`](tea-ceremony.jpg) — китайская чайная церемония («понедельник, 14:00, и ты сам решаешь»)
- Шрифты: [`fonts/`](fonts) — Lora (заголовки) и Inter (всё остальное), variable TTF с кириллицей, SIL OFL

## Основной формат

Илья снимает себя на камеру и рассказывает про нишу → пайплайн `talking-head`.
Платные ключи не используются: распознавание речи — локальный `faster-whisper`
(`transcriber`), без генерации картинок/видео/озвучки.

Типовая сборка: вырезать паузы и оговорки (`silence_cutter`) → 9:16 (`auto_reframe`)
→ лёгкая цветокоррекция (`color_grade`) → субтитры по словам (`remotion_caption_burn`)
→ тихая музыка (`pixabay_music`, громкость 0.08, ducking под голос).

## Субтитры (`remotion_caption_burn`, простой режим)

Проверено рендером 2026-10-14: кириллица в Inter, плашка и подсветка корректны.

```json
{
  "words_per_page": 3,
  "font_size": 64,
  "highlight_color": "#F28A2E",
  "caption_color": "#FFFFFF",
  "caption_background_color": "rgba(20, 24, 58, 0.80)",
  "caption_font_family": "Inter, sans-serif"
}
```

Передавай `corrections` для терминов, которые whisper путает: `{"рко": "РКО", "ип": "ИП", "т-банк": "Т-Банк", "псб": "ПСБ", "втб": "ВТБ", "аусн": "АУСН", "нпд": "НПД"}`.

Шрифты должны быть видны Chromium: перед рендером
`mkdir -p ~/.fonts && cp brand/jirafik-trafik/fonts/*.ttf ~/.fonts/ && fc-cache -f`.

**Облачная сессия Claude Code:** Remotion не может скачать свой браузер
(`ENOTFOUND remotion.media`). Рендерь с
`--browser-executable=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`
(команду `npx remotion render TalkingHead --props=...` можно запустить вручную из
`remotion-composer/` с тем же props-файлом, который пишет инструмент).

## Голос бренда (для заголовков, текста на экране, описаний)

- На «ты», как старший друг, который прошёл этот путь. Со взрослыми клиентами на регистрации — на «вы».
- Живо, с кусочками жизни, честно про подвохи. Сложное — через простую логику. В конце — вопрос к аудитории.
- Так звучим: «Не „кнопку бабло“ и не 40 уроков воды за 50к. Только то, чем пользуемся сами». «Вопрос не „заплатит или кинет“. Вопрос — выполнил ты условие или нет».
- Так не звучим: канцелярит, обещания лёгких миллионов, давление («осталось 2 места»), мат, высокомерие к новичкам, сухая заумь.
- Эмодзи — 1–3 на пост, как акцент.

## Аудитория

18–25 лет, «хотят зарабатывать и быть свободными»: новички в онлайн-заработке
(TikTok/YouTube/Instagram), начинающие ИП и самозанятые, люди в поиске подработки (Авито).

## Монтажные приёмы (из референсов Ильи)

Это набор инструментов, а не чек-лист: в ролик берём только то, что усиливает
конкретный момент. Неиспользованное — для следующих роликов.

- **Хук 0–2.5 с.** Крупный заголовок по центру кадра, смешение шрифтов: строка
  ЗАГЛАВНЫМИ Inter 900 + ключевое слово курсивом Lora оранжевым со свечением.
  Хорошо работает «результат сначала»: 0.5 с вспышка суммы/итога, потом заголовок.
  Открытая петля («скрин выплаты — в конце 👀») — только если в конце правда это есть.
- **Субтитры** (`captionStyle: "bold"`): по 1–2 слова, без плашки, белые ЗАГЛАВНЫЕ
  с тенью, слово появляется ровно когда сказано. Ключевые слова (`key: true`) —
  отдельной страницей, Lora italic оранжевым с тёмной обводкой.
- **Звук под ключевое слово** (`sfx`): клик — действие/кнопка/звонок, печать
  клавиатуры — работа за ноутбуком/«настроить»/«отчёты», поп — лёгкий акцент,
  вжух — переход/отдых, монеты — деньги, райзер — перед раскрытием результата.
  Громкость тихо (0.2–0.5), не чаще одного звука на 2–3 секунды.
- **Плавность:** без рывков и размытия на каждой склейке, только мягкий наезд.
- **В запасе:** «ТЫК»/звукоподражания на касаниях, рука-указатель и кружок
  на интерфейсе (туториалы, скринкасты), метка «ПРАВИЛО #1» / «ШАГ 2» для
  роликов-списков, мокап телефона для показа приложений, счётчик-проценты.
- **Финал-награда:** скрин результата с растущим счётчиком; подписывать точно,
  что это (например «личный кабинет Ozon Банка»), не выдавать за итог периода.
