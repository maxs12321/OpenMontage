# Библиотека материалов «Жирафик Трафик»

Материалы, которые Илья присылает для монтажа. Агент берёт их в ролики по своему
решению, когда они усиливают смысл или удержание. Отдельно спрашивать не нужно.

| Папка | Что лежит | Как использовать |
|---|---|---|
| `photos/` | фото Ильи, команды, рабочих моментов | вставки 0.5–1.5 с, фон для плашек, обложки |
| `screenshots/` | выплаты, кабинеты партнёрок, приложения банков, чаты | доказательства на словах о деньгах/результате; **личные данные и номера счетов размывать** |
| `mascot/` | жираф в разных позах (PNG с прозрачным фоном) | стикер-реакция на ключевых словах, концовка |
| `broll/` | сырые клипы 3–10 с | перебивки под голос вместо статичных планов |
| `music/` | треки под вайб блога | фон под голос, громкость ~0.08, приглушать под речь |
| `memes/` | мемы, реакции, стикеры | 1 мем на ролик максимум, на смешных моментах |

Правила: стиль из [`../README.md`](../README.md), не больше одного «золотого» элемента
на экране, монтаж плавный (без рывков на каждой склейке).
Тяжёлые видео (>20 МБ) в git не кладём — хранить на Google Диске, в репозитории
только ссылка в `broll/LINKS.md`.
