# Как монтировать ролики Ильи — главный регламент

Это сводка всех рекомендаций Ильи по итогам первых роликов (октябрь 2026).
Читать перед любым монтажом. Подробности и история — в [`README.md`](README.md).

**Главный принцип: инструменты — не чек-лист.** Каждый приём берём только там, где он уместен
по смыслу конкретного ролика. Лучше меньше, но точно. Перебор = «дёргано» и «отталкивает».


## ГЛАВНОЕ: качество исходника не портить (решение Ильи)

Исходник — очень плавная и чистая картинка, её надо сохранить. Лишнего не выдумывать.
- Никаких «улучшающих» фильтров: без unsharp/резкости, без eq (контраст/насыщенность/гамма), без colorchannelmixer, без
  маскировок/закрашиваний (фильтр индикатора микрофона — не использовать вообще).
- Цвет: только нейтральный перевод HLG/HDR → SDR (zscale + tonemap), без художественных правок. Перед первым роликом в новом
  месте/свете — прислать кадр «исходник / мой результат» рядом.
- Минимум пережатий: промежуточные файлы почти без потерь (crf ≤ 8 или lossless), сжимать один раз — на выдаче. 60 fps (максимум
  TikTok), без выкидывания/дублирования кадров.
- Что Илье нравится и остаётся: субтитры, тексты/плашки, переходы, звуки.
- Конвейер (утверждён на ролике «150 000 ₽ за первый месяц»): `scripts/jirafik/prep_neutral.py` (tonemap mobius, npl 203,
  дизеринг, 1440×2560 60 fps crf 8 — приближения не мылят) → склейка crf 8 → Remotion `--crf=6` → один финальный кодек crf 12
  (`render_neutral_example.sh`). Файл > 190 МБ отдавать через страницу с частями в хранилище (как YouTube-ролик).

## Подготовка новой сессии (облако чистое после перезапуска)

1. `make setup`, затем `.venv/bin/pip install faster-whisper sherpa-onnx pillow-heif`.
2. Модели (с GitHub, Hugging Face заблокирован):
   - речь RU с таймингами слов: `sherpa-onnx-nemo-transducer-giga-am-v2-russian-2025-04-19` → `/home/user/models/`;
   - Whisper turbo (сверка текста): `sherpa-onnx-whisper-turbo`; VAD: `silero_vad.onnx`;
   - вырезка человека: `rvm_mobilenetv3_fp32.onnx` (PeterL1n/RobustVideoMatting) → `/home/user/models/rvm/`.
3. Шрифты: `cp brand/jirafik-trafik/fonts/*.ttf ~/.fonts/ && fc-cache -f`.
4. Remotion рендерить с `--browser-executable=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`.
5. Скрипты: `scripts/jirafik/` (asr.py, giga.py, matte.py, headpos.py, пример props_example_banks.py).
6. Звуки (`remotion-composer/public/jirafik/sfx2-*`, `sfx3-*`) вырезаны из обучающих видео Ильи —
   в git их нет; если пропали, попросить Илью прислать обучающие ролики со звуками заново.

## Процесс

1. Илья присылает отрывки (по 4–6 с, 4K HDR с iPhone) → склеить по порядку в мастер.
2. Расшифровать (GigaAM + Whisper), **непонятные слова/названия — спросить Илью** (банки, термины, имена).
3. Вырезать паузы между фразами. Ролик заканчивается на последней фразе, мягкое затемнение 0.4 с.
4. Собрать в `JirafikVlog` (Remotion), проверить кадры, отрендерить.
5. Отдать: HEVC-версию ≤ 30 МБ в чат + полное качество через страницу-артефакт с кнопкой «Скачать».

## Картинка

- **Цвет натуральный, как на iPhone, без «мыла»** (с 26.10, по фидбеку Ильи): HLG →
  `tonemap=hable` при **npl=150** + `eq=contrast=1.07:saturation=1.08:gamma=1.04`
  + `colorchannelmixer=rr=0.99:bb=1.03` + лёгкая резкость `unsharp=5:5:0.55`.
  Старый вариант (npl=100 + curves + сильный синий сдвиг) давал розоватую плоскую картинку — не использовать.
  Сначала уменьшить до 1080, потом tonemap (быстрее). Пример: `projects/vid7/prep.py`.
- **Ракурс меняется каждые ~5 с** на планах с Ильёй: общий → средний (+0.16) → общий → крупный (+0.26),
  `jumpRanges` = `[start, end, zoom, originY%, originX%]`, приближение — к лицу (позиция из маски).
  Смена — на паузе между словами или на склейке; не во время крупного текста за спиной.
  **Приближение — просто приближение, без сдвига вбок:** originX всегда 50 %. Илья попросил: камеру в сторону не уводить.
  По вертикали — если сверху много пустой стены, якорить к нижнему краю (originY 100 %), иначе по центру (50 %).
  Плавный наезд камеры еле заметный (`push 0.015`).
- **Переходы** (обучающее видео Ильи) — на смене типа кадра: заставка → Илья, Илья → экран, экран → Илья.
  Каждый со своим звуком (`transitions` + `sfx`):

  | Переход (`type`) | Что видно | Звук |
  |---|---|---|
  | `whip` (основной) | оба кадра проезжают вбок с размытием в движении (`dir` 1/-1 чередовать) | `sfx2-swipe` |
  | `zoomin` | наезд «сквозь» кадр с размытием в следующий | `sfx2-zoom` (Fuwa) |
  | `dissolve` | последний кадр с Ильёй плавно растворяется (с лёгким размытием) в следующий кадр — для перехода к тёмному куску, когда графика (таблица) остаётся на экране. `blurin` для этого НЕ использовать — Илье показался рваным | `sfx2-whoosh-short` (тихо) |
  | `flash` | засветка + тёплый блик | `sfx3-camera-shutter` |
  | `stretch` / `click` / `glitch` | запасные, Илье не понравились как сделаны — не использовать без нужды | — |

  **«Тетрис» (рассыпание на квадраты) — никогда.** Склейки внутри одного плана — без переходов.
  **Склейка без чёрных кадров:** границы планов брать по реальной смене кадра (скачок яркости по кадрам), куски резать ровно по сетке 60 fps (`-frames:v`), иначе склейка «уезжает» и на стыке мелькает чёрный кадр из исходника. После сборки проверить, что в склейке нет кадров с резким провалом яркости.
  **Звук на склейках:** никаких затуханий в ноль на каждом куске — дырка в фоне комнаты слышна в наушниках как щелчок. Звук собирать из исходника целиком с перекрёстными переходами 40 мс по центру склейки, точку реза ставить в самое тихое место паузы (не на вдох и не на хвост слога). Перед этим срезать гул ниже 100 Гц (`highpass=f=100:poles=2` ×2): с телефона его не слышно, а в наушниках он прыгает на каждой склейке.
  **Исходник — без фоновой музыки.** Если в записи уже играет трек, он рвётся на каждой склейке (в наушниках — «помехи, скрип»). Проверить паузы: если там не тишина, а музыка — попросить у Ильи версию без трека, музыку он накладывает сам. Звук можно подменить, не трогая монтаж (`projects/vid8/reaudio.py`: те же куски, звук из нового файла, `adeclick`).
  Где реальные смены кадра — определять по картинке (`ffmpeg … select='gt(scene,0.25)'`), не по длине кусков.
- **Без полоски прогресса** сверху.

## Текст на экране

- **Хук** (первые ~2–3 с): внизу кадра 2 строки узким Oswald — одна оранжевая, одна белая,
  над ними мелкая подпись курсивом. Держится, пока Илья это говорит. Без нагромождения.
  Обещание в подписи — только правдивое (что реально будет в ролике).
- **Субтитры**: одно слово за раз, белый Inter жирный курсив строчными, по центру, без обводки,
  мягкая тень, лёгкий отскок. Ключевые слова — на оранжевой плашке. Числа — цифрами («33 000 ₽»).
  Синхрон по словам (GigaAM), проверять по кадрам.
- **Крупный текст ЗА человеком** — красиво, использовать, когда уместно: названия банков/сервисов,
  главные сущности. НЕ эмоциональные слова («соврал», «бесплатно»). По слогам столбиком, **по центру,
  в безопасной зоне TikTok** (ширина ≤ 740 px, не выше **340 px** сверху — иначе перекроют кнопки/интерфейс),
  голова чуть перекрывает низ букв (позиция по голове из маски). **Шрифт меняется по смыслу** (Unbounded,
  Russo One, Lora Italic и т.д.), не всё одним Oswald.
- **Плашки на светлом видео — светлые** (белые карточки, тёмно-синий текст, оранжевый акцент).
  Для роликов-списков: «№1 Банк · сумма», карточка расчёта, призыв в Telegram в конце.

## Звук

**Звук = своя анимация** (из обучающего видео Ильи «лучшие звуки для анимации текста»). Звук ставится
только вместе с той анимацией, под которую он сделан, — в props слову задаётся `anim`, и звук идёт в его начало:

| Анимация (`anim`) | Что делает текст | Звук |
|---|---|---|
| `scale` (масштаб) | слово быстро вырастает из маленького | `sfx2-whoosh-short` |
| `rotate` (поворот) | слово доворачивается из наклона | `sfx2-paper-turn` |
| `type` (печатание) | слово набирается по буквам | `sfx2-typing-real` |
| `zoom` | огромное слово влетает справа и сжимается | `sfx2-zoom` (Fuwa) |
| `appear` (появление) | мягко проявляется из размытия, буквы сходятся | `sfx2-appear` |
| `flicker` (мерцание) | слово мигает и загорается | `sfx2-charge` |
| `count` (счёт) | число бежит до значения | `sfx2-gauge` |
| скрин/карточка выезжает снизу | — | `sfx2-swipe` |
| крупный текст за спиной (влетает огромным) | — | `sfx2-zoom` |

- **Не собирать всё в одном ролике.** На минуту видео ~6–7 звуков. Основа — одна пара (`scale` + вжух),
  она повторяется на 3–4 главных словах. Особые пары (мерцание, печать, поворот…) — 1–2 за ролик, только
  в самый сильный момент. Остальные ключевые слова — просто оранжевая плашка, без звука.
- Анимацию выбирать по смыслу: «заблокированы» — мерцание, «отчётность» — печать, «пуэр» — поворот,
  название банка — zoom, суммы — счёт.
- Сколько звуков — столько появлений: нет анимации — нет звука. Звуки тише голоса, не ближе 0.3 с.
- Синтезированных звуков не делать. Пример: `scripts/jirafik/props_example_day2.py` (PAIR/plan), `remotion-composer/public/demo-props/jirafik-day2.json`.

## Правда

- Суммы/выплаты/результаты — только то, что Илья сам говорит или подтвердил. «Итог дня» деньгами
  не показывать (доход считается в конце месяца). Подписи к скринам точные.
- Личные данные (ФИО, ИНН, телефоны, номера карт) на скринах — размывать. Скрины с деньгами и фото
  с лицами в публичный git не класть.
- Без концовки с жирафом, если Илья не попросит.

## Удачные форматы (Илья одобрил)

- **«Реф-ссылка банка vs партнёрская сеть»** (`jirafik-ref5.json`, `scripts/jirafik/props_example_ref5.py`):
  превью (b-roll + заголовок внизу, вторая строка появляется на слове) → Илья → экран партнёрки
  под его голос (голос записан отдельно) → анимация сравнения `compare` на размытом фоне
  (карточки со скринами, у лучшего — счётчик, худший зачёркивается на «не туда») → Илья + плашка Telegram.
  Голос, записанный отдельно, — брать только текст, обращения к Claude вырезать.

## Качество по умолчанию — максимум TikTok (решение Ильи)

- **Всегда 1080×1920, 60 к/с.** TikTok показывает максимум 1080p и 60 к/с — больше он пережимает.
  Исходники iPhone 4K HLG 120 к/с: клипы готовить сразу в 1080×1920 **fps=60** (сначала уменьшить,
  потом tonemap — быстрее), в props `"fps": 60` (анимации держат тайминг сами).
- **Рендер Remotion всегда с `--image-format=png`** (по умолчанию Remotion снимает кадры в JPEG 80 % —
  это мыло и артефакты до сжатия), `--crf=12`.
- Отдавать **H.264** (High, `-crf 10 -preset slow`, ~17–20 Мбит/с, AAC 48 кГц) — его без проблем принимают AirDrop, «Фото» и TikTok;
  Страница скачивания вмещает до 256 МБ в base64, то есть файл ≤ ~190 МБ: если HQ на crf 10 больше — пережать на crf 12 (на глаз разницы нет).
  HQ-файл через страницу скачивания + версия ≤ 30 МБ в чат (тоже 60 к/с).
- Илье в TikTok загружать **HQ-файл со страницы**, а не версию из чата; в настройках TikTok включить
  «Загрузка в высоком качестве»; не накладывать в TikTok свои фильтры/текст (он пережимает сильнее).
- 4K — только если Илья отдельно попросит (для YouTube), ~1 час рендера: клипы 2160×3840, `--scale=2`.
- **Маска человека (`matte.py`) пишется с частотой кадров исходника** — иначе на 60 к/с вырезка
  отстаёт и человек «отклеивается» в моменты крупного текста за спиной. Проверять кадр с bigWord.
  Для скорости маску можно считать только в окне крупного текста: `matte.py in.mp4 out.webm 3.4 6.4`.
- По времени (4 ядра): 30-секундный ролик в 1080p60 ≈ 25 мин. Если Илье срочно — предупредить заранее.
- Пример конвейера: `scripts/jirafik/run60_example.sh`.

## Безопасная зона TikTok и размытие (с 26.10)

- Никакой текст/карточки не выше **330–340 px** сверху (там вкладки TikTok) и не правее ~950 px.
- **Размывать фон только там, где в исходнике тёмный экран** (Илья говорит за кадром).
  Пока Илья в кадре — графика компактная, над головой, он виден чётко (таблица в 2 колонки, `columns: 2`, `blur: false`).

## Длинные ролики для YouTube (16:9)

- Формат: 1920×1080, 60 fps, H.264 crf 17 (maxrate 14M) — ~11 Мбит/с, ≈ 800 МБ на 10 минут. Стиль спокойный: без звуков на каждом событии,
  только тихий «вжух» на заголовках глав.
- Сборка без Remotion (10 минут в Remotion слишком долго): `scripts/jirafik/build_example_youtube9.py` (паузы > 0,6 с ужимаются,
  «ээ/у…» вырезаются, звук склеивается перекрёстными переходами), `gfx_example_youtube9.py` (карточки PNG + субтитры ASS),
  `final_example_youtube9.py` (наложение и кодирование).
- Планы: общий ↔ ближний 1,2× примерно каждые 15–20 с, только на естественных паузах; приближение строго по центру по X,
  сверху якорь (голова не режется).
- Графика: слева сверху — плашка главы («01 Кто я», «Ошибка 2 …»); справа — карточка с цифрой, таблица банков, шаги пути клиента
  (строки появляются, когда Илья их называет); в конце — Telegram @jirafiktrafik. В Russo One нет знаков «₽» и «−» — их рисовать Inter.
- Субтитры: фразы до ~40 символов, белый Inter Bold с обводкой внизу; текст = тайминги GigaAM + пунктуация/цифры Whisper
  (`align_subs.py`), ошибки распознавания править вручную.
- Зелёный индикатор петлички гасить `scripts/jirafik/deled_mic_led.py` ТОЛЬКО если Илья сам попросил и фон не зелёный. В TikTok-роликах по умолчанию НЕ трогать: на зелёной подсветке/фоне фильтр рисовал чёрные квадраты.
- Отдача: страница скачивания, где файл лежит частями (по 14,5 МБ с 4-байтной меткой) в хранилище артефакта (до 1 ГБ),
  страница склеивает их и сохраняет. Плюс таймкоды глав для описания YouTube.
- Загрузка от Ильи больших файлов: страница загрузки ждёт, пока Claude заберёт и удалит части, и продолжает сама; к каждой части
  добавляется метка «JVK1» (иначе кусок, начинающийся с «<», отклоняется как разметка).
